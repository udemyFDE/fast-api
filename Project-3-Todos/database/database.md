## Database
* A database is an organized collection of structure collection of data, which is stored in a computer system.
    - The data can be easily accessed.
    - The data can be modified.
    - The data can be controlled and organized.
    - Many databases use `Structure Query Language (SQL)` to write and/or modify the data.

* Database is a collection of data and allows the management of data.
* Databases are organized in how the data can be retrieved, stored and modified.
* `DBMS (Database management system)` - kind of a parent database to manage databases and is of many types. (SQLLite, MySQL, PostgreSQL)
* `SQL` &rarr; Standard language for dealing with `relational databases` which means having `tables` with rows and cloumns.
