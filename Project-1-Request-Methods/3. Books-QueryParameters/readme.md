## Query Parameters
* query parameters are request parameters that have been attached after a "?" question mark.

* query parameters have a `name=value` pair relationship.
eg:
> http://127.0.0.1/books/?category=math

* query parameters can be used with path parameters.
eg:
>http://127.0.0.1/books/author%20four/?category=science

* It is a way to filter data based on the URL provided.
