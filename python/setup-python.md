## For Windows
* Go to the official python website &rarr; https://www.python.org

* select the download for windows (version) and while running the executable ensure to tick the box for `add python.exe to PATH`

* After installtion, verify the version by running the below command in command prompt
```
python --version
```

* To open python editor
```
python
```
> Sample print statement

```
print("Hello World!")
```

* To exit from python terminal/editor Press `Ctrl + Z` and then hit `Enter`
