# FastAPI
* FastAPI is a Python web framework for building modern APIs.
    - Fast (Performance)
        - Fast API is one of the fastest performing web frameworks on the market. But we also get data validation, serialization, documentation and more, which is all included.
    - Fast (Developement)
        - makes easy to create the backend communication that has embedded security, lightweight installation and can be running within minutes.
* Simply put, Fast API is a web framework for building modern restful APIs. 
* _Learn more on fastapi offical documentaiton_ -- (https://fastapi.tiangolo.com/)

* Key points:
    - Few Bugs
        - Fast API allows you to develop APIs with fewer bugs with all the data validation that is embedded. You can see the reduction of about 40% of human errors and bugs.
    - Quick & Easy
        - Fast API was designed with the developer in mind. This makes fast API easy to use and easy to learn. This saves you time to keep building products
    - Robust
        - within minutes get production ready code with an automatic and dynamic documentation.
    - Standards
        - Fast API uses the open API standards and JSON schema.

**_Where does fast API fit within the application architecture?_**

* you have your web page -- This is what the user is going to be interacting with.

* Then you have your server running the fast API application that handles all business logic for your web page.

    - In modern programming, a web page communicates to a server application through restful APIs.
    - RESTful APIs from the web page side of things requests data from the backend server business logic.
    - fast API's responsibility here is to ensure the web page is getting correct and secure data for their users to interact with.

* Fast API can also leverage additional tools to create full stack applications where Fast API is not only responsible for the business logic but also renders the front web page.


**who has used fast API?**
